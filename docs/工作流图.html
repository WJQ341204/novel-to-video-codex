一条命令

# 全链：渲染 + 配音 + faststart + 报告
python scripts/flow.py --cast --style --neg base,face

# 只补渲染部分场景（其余按参数指纹自动跳过）
python scripts/flow.py --only 4 8 12 --cast --style --neg base,face

# 渲染已完成，只跑配音 + faststart + 报告
python scripts/flow.py --skip-render

# 先看会执行什么，不动 GPU
python scripts/flow.py --dry-run

断点与护栏

  • 状态文件：output/novel_demo_v2/run_state.json，每步记「参数指纹 + 产物路径」。参数一变指纹失配 → 自动重做该步；不变 → 跳过。
  • 产物门槛：单文件 < 5000 字节视为半成品，不认（防 ffmpeg 写一半崩溃留下的坏片）。
  • 自动备份：backup_if_exists() 在出图 / 落尾帧 / 写成片覆盖前留 .bak。
  • 中断恢复：直接重跑同一条 flow.py 命令，从第一个未完成步骤继续。
