> 前提声明：**我只读到该包的文件名与体积，没读到文件内容**（下载需登录态）。

---

## 一句话结论

**差距不在工程管线，在内容层。**

我们的出图→出视频→配音→合成这条线是跑通的、可复现的、本地闭环的；
但资源包花了 7 个 skill + 4 个提示词库去覆盖的**"剧本质量、人物小传、运镜与风格、质检"**，
我们几乎是空白。

直白点说：**我们会"把一幕做出来"，但还不会"把一场戏写好"。**

## 反过来：资源包没有、而我们有的（别妄自菲薄）

| 我们有 | 说明 |
|---|---|
| **端到端真跑通的本地管线** | 它有教程和模板，我们有**实际产出**（两支成片、8 支分镜视频） |

| **首尾帧落点方案** | 首帧-only 模型上用 xfade 近似双关键帧 |

## 补齐路线（按 ROI 排序）

### 第 1 步：人物小传体系化 —— 半天，立竿见影

现在 `cast.json` 里的角色只有一句英文 anchor。扩成小传结构：

```json
"叶玄机": {
  "anchor": "a young Chinese man with short dark hair, calm steady gaze, dark teal cotton jacket",
  "bio": {
    "age": "二十出头",
    "identity": "游方医者",
    "personality": "话少、观察力强、不轻易示弱",
    "backstory": "师门遭难后独自南下寻访青囊残卷",
    "costume": "深青布衣，背旧药箱，腰间悬半枚铜铃",
    "habits": "思考时摩挲药箱铜扣",
    "voice_style": "偏低、语速慢、少用语气词"
  },
  "voice": "boyinnanshi", "mood": "平静", "intensity": 4
}
```

`bio` 直接参与 prompt 拼装（对应资源包的"人物提示词公式表"），
`voice_style` 指导 TTS 情绪选择。**这是把 cast.json 从"配置表"升级成"角色卡"的关键一步。**

### 第 2 步：加剧本环节 —— 别再从小说一步跳到分镜

现在：`小说 → 分镜`。改成：`小说 → 剧本（结构框架 + 爽点设计）→ 分镜`。
剧本层只需产出三样东西：结构框架（起承转合/集内节拍）、爽点清单（每集钩子）、逻辑校验结果。

对应到代码：在 `SCENES` 之前加一层 `SCRIPT`，分镜从剧本推导而非从原文推导。
**这一步是差距最大的，也是最能拉开成片观感的。**

### 第 3 步：建 `prompts/` 素材库 —— 一天，收益持续

```
prompts/
├── camera.md          运镜词典（推/拉/摇/移/跟/环绕 + 微动静）
├── style.md           风格模板（古风/暗调悬疑/水墨…）
├── micro_expression.md 微表情（眼神、嘴角、呼吸、手指）
└── neg.md             负面词基线（按题材分档）
```

脚本改成引用词典 key，而不是把长 prompt 硬编码在 `SCENES` 里。
这样写完一次，后面所有片子都能复用。

### 第 4 步：风格模板进 cast.json

```json
"style": {
  "active": "古风·胡金铨",
  "prompt_add": "ink-wash mood, misty mountain air, bamboo shadow, minimalist composition",
  "neg_add": "neon, cyberpunk, modern clothing",
  "color": "cold ink with warm amber lamp",
  "lens": "35mm anamorphic, shallow depth"
}
```

全片套用，换风格只改一处（对应 DramaClaw 的「虾格」）。

### 第 5 步：加质检清单

照 `luoji-jiaoyan-qingdan.md` 的思路建 `docs/出品自检清单.md`，每次出片前过一遍：
因果链是否成立 / 静音能否看懂 / 角色身份是否锁定 / 接触物理是否合理 / 文字是否后期叠加。
做成 `scripts/verify_scenes.py` 的扩展，不合格直接拦下。

---

## 优先级建议

| 顺序 | 事项 | 为什么先做 |
|---|---|---|
| 1 | 人物小传体系化 | 半天完成，直接提升出图稳定性和角色辨识度 |
| 2 | `prompts/` 素材库 | 一次投入，之后每部片子都省事 |
| 3 | 加剧本环节 | 差距最大，但要动主流程，得单独一轮 |
| 4 | 风格模板 | 依赖素材库建好 |
| 5 | 质检清单 | 等前面稳定了再加，否则天天被拦 |

**暂缓**：宫格批量分镜、Coze 式可视化编排——我们走本地路线，这两样性价比低。
