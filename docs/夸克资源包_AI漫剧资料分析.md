## 一、先说结论：它不是一个"项目"

**这是「AI 漫剧/短剧」的资料合集，不是可运行的工程。** 里面没有代码仓库、没有可执行流水线，
内容是：视频课程 + Agent Skill 包 + Coze 工作流源码 + 提示词表格 + 故事板案例。

更关键的一点：**它的技术路线和本项目是相反的。**

| | 这个资源包 | 墨影流光（本项目） |
|---|---|---|
| 算力 | 全云端（Seedance 2.0 / 可灵 / Sora2 / Nano Banana Pro / GPT-Image-2） | 本地 8GB 显卡（ComfyUI + SDXL + Wan2.2） |
| 编排 | Coze 工作流（需第三方 Key） | Python 脚本直驱 ComfyUI |
| 后期 | 剪映 | ffmpeg |
| 一致性 | 角色卡 + 提示词模板（文本层） | IPAdapter / LoRA（图像层）+ 新建的 cast.json |
| 门槛 | 花钱买 API，出片快 | 一次性硬件，稿件不出机 |

所以别指望照搬它的工作流——那些 Coze 包绑死在 Coze + 云端模型上，搬不过来。

## 四、三点提醒

1. **时效性强、贬值快**：整个包围绕 Seedance 2.0 / Nano Banana Pro 这类云端模型，
   模型半年一换代，教程里的界面与参数很快失效。**方法论（分镜结构、爽点节奏、角色卡字段）才耐久，
   具体参数和按钮不耐久。**
2. **来源混杂**：这类"整合版"网盘包通常是二次收集分发，付费课程与开源素材混在一起，
   自用学习可以，**不要把自己项目的代码里塞进去再分发**。
3. **我只看到文件名和体积，没读到内容**——夸克下载接口要登录态。上面"含金量"判断是基于
   文件名、体积和 Skill 包结构做的推断，**下载后需要实际核对**。
