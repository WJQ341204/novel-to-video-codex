## A 级 · 卡脖子（不做就出不了商业级成片）

### A1 角色一致性只到文本层 —— 最大质量缺口
- 现状：`--cast` 是把 cast.json 的 `look` 拼进 prompt（文本锚定），**跨幕长相仍靠运气**。
- 证据：`engines/wan5b.py` 的工作流里没有 IPAdapter / PuLID / InstantID / ReActor 节点；
  `cast.py` 里 `ipadapter_weight` 只是预留字段；`diag_consistency2.py` 是诊断脚本不是实现。
- 缺什么（按性价比）：
  1. **角色 LoRA**（10-40 张，1024，lr≈1e-4，推理权重 0.6-0.8）—— 本地可训，一致性提升最大
  2. **IP-Adapter / PuLID + FaceID**（权重 ~0.8）—— 需 ComfyUI 装对应节点 + 反复试权重
  3. **ReActor / InstantID 换脸兜底** —— 出图后修脸，救废片
- 工作量：LoRA 1-2 天（含训练）；IPAdapter 半天接线 + 半天调权重。

### A2 剧本层建好了但没接进主链
- 现状：`scripts/script_layer.py`（小说→剧本→分镜，`check()` 8 类校验）+ `story/青囊_剧本.json` 已就绪；
  但 `flow.py` / `novel_video.py` **完全没调用它**——小说仍是直接进分镜。
- 缺什么：`flow.py` 增加 `--from-novel <file>` 阶段，先跑 `script_layer.check()`，
  校验不过就停（hook / 节拍 / 爽点 / 静音可懂 / 角色已注册 / 声线已分配 / 运镜微表情在词典内）。
- 工作量：半天接线。

### A3 竖屏 9:16 不支持
- 现状：`scripts/novel_video.py` 第 39 行 `W, H = 1280, 704` 写死横屏；README 却宣称"竖屏短视频"。
- 缺什么：`W/H` 改成可配置（16:9 / 9:16 / 1:1），字幕与合成跟着自适应。
- 工作量：2-4 小时。

## C 级 · 工程健壮性

| # | 缺口 | 说明 |
|---|---|---|
| C1 | **质检未自动化** | `docs/出品自检清单.md`、`scripts/verify_scenes.py` 存在，但 `flow.py` 不跑 |
| C2 | **ComfyUI 掉线无感知** | 今天实测：ComfyUI 已停，`flow.py` 预检只打印警告仍继续（应硬失败或自动拉起） |

| C5 | **无耗时 / 成本统计** | 多幕串行跑完才知道总耗时，缺每幕计时与汇总 |

| C7 | **`compose()` 输出名写死（会覆盖别的片子）** | `novel_video.py` 第 376 行 `final = OUT / "青囊异闻录_雨夜药铺.mp4"` **不看 scene_ids**——渲染 101/102（司马谷岩之战）时同样往这个名字写，会把青囊成片直接覆盖。2026-09-28 实测踩到，靠提前备份才没丢片。修法：输出名按场景集派生，或加 `--out-name` 参数 |

## 建议推进顺序（ROI 排序）

```
A2 剧本层接线（半天，把已有资产用起来）
  ↓
A3 竖屏支持（2-4h，短剧主流格式）
  ↓
B1 BGM 接线（1-2h，观感提升最直观）
  ↓
A1 角色 LoRA（1-2 天，画质天花板）
  ↓
C1/C2/C3 质检与容错（1 天，让流水线能无人值守）
  ↓
B4 图池选优 → B2 超分 → B3 转场
```

## 一句话结论

**内容层的"剧本环节"和"角色一致性"是真正的分水岭**——前者代码已写好只差接线（半天），
后者决定成片能不能看（1-2 天）。其余都是锦上添花。
