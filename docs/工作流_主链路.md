## 一条命令

```bash
# 全链（渲染 + 配音 + faststart + 报告）
python scripts/flow.py --cast --style --neg base,face

# 只补渲染部分场景（其余自动跳过——断点续跑按参数指纹判断）
python scripts/flow.py --only 4 8 12 --cast --style --neg base,face

# 渲染已完成：只跑 配音+faststart+报告
python scripts/flow.py --skip-render

# 先看会执行什么，不动 GPU
python scripts/flow.py --dry-run
```

## 各环节明细

| # | 环节 | 实现 | 关键保证 |
|---|------|------|----------|
| 1 | 剧本 | `scripts/script_layer.py` · `story/青囊_剧本.json` | `check()` 8 类校验零 ERROR 才进渲染 |
| 2 | 关键帧 | `novel_video.py --cast --style --neg` | cast.json 锚定外貌 / 全片风格 / 分档负面词（prompts/neg.md 10 档） |
| 3 | 图生视频 | Wan2.2-TI2V-5B (Q5_K_M) · ComfyUI :8188 | 首帧专用 i2v；seed 用 hashlib 确定性派生，可复现 |
| 4 | 尾帧落点 | `land_end_frame()` xfade fade 0.8s | 首帧-only 模型上近似"双关键帧"收尾 |
| 5 | 合成 | `compose()` 字幕烧录 + concat copy | 两段式字幕：灰白=旁白(不配音) / 暖黄=台词(配音) |
| 6 | 配音 | `add_stepfun_tts.py` | 声线三级解析：shot_overrides > 角色 > 默认（cast.py `voice_for`） |
| 7 | 流式优化 | `flow.py` box 自检 + `-c copy -movflags +faststart` | ftyp→moov→mdat，浏览器边下边播 |

## 断点与恢复

- **状态**：`output/novel_demo_v2/run_state.json`，每步记录 `参数指纹 + 产物路径`。
  参数一变（改 prompt / 换旗标）指纹失配 → 自动重做该步；指纹不变 → 跳过。
- **产物门槛**：单文件 < 5000 字节视为半成品，不认（防 ffmpeg 写一半崩溃留下的坏片）。
- **自动备份**：`backup_if_exists()` 在出图 / 落尾帧覆盖前自动留 `.bak`。
- **中断恢复**：直接重跑同一条 `flow.py` 命令即可，从第一个未完成步骤继续。

## 常见问题

- **ComfyUI 必须在线**（127.0.0.1:8188），`flow.py` 预检会提示。
- **ffmpeg 不在 PATH**：`flow.py` 已内置绝对路径，无需配置。
- **渲染很慢（20min+/幕）**：分档负面词加长后 umt5 编码变慢，属正常；一幕 5-22 分钟波动。
- **成片在浏览器卡住不播**：九成是 moov 在尾部，重跑 `flow.py --skip-render` 会自动重封装。
