# 出品自检清单

出片前逐项过一遍。**任一项 ERROR 不得交付。**
（对照资源包的「逻辑校验清单」建立——以前我们是出片即交付，没有任何质检。）

---

## 0. 剧本层（自动）

```
python scripts/script_layer.py check story/<剧本>.json
```

要求：**零 ERROR**。WARN 逐条确认是否可接受。
自动检查项：钩子 / 节拍 / 爽点 / beat 引用 / 静音可懂 / 角色已登记 / 声线已配 /
运镜与微表情在词典内 / 相邻幕不重复叙事 / 总时长 10~20s。

## 1. 出图前

- [ ] 所有出场角色都在 `assets/cast.json` 的 `characters` 里（**不在就会串脸**）
- [ ] 角色有 `look`（详细外貌）而不只是 `anchor`（精简锚点）
- [ ] `active_style` 已选定（换风格只改这一处，不要改脚本）
- [ ] 负面词已选分档（`--neg base,face`；古装加 `costume`，室内加 `interior`）
- [ ] 单条负面词不超过 40 个词（过多会压制画质）

## 2. 出图后（一致性门禁）

- [ ] **同一角色跨镜是同一张脸**——把各镜首帧摆一起看，不像就重出
- [ ] 服装/发型/配饰与 `bio.costume` 一致（最容易漂的是衣服颜色和有没有胡须）
- [ ] 无六指、无多余肢体、无崩脸
- [ ] 画面里没有水印和乱码文字（古装尤其容易出招牌错字）
- [ ] 若开了 `--cast`，确认 IPAdapter 权重 ≤ 0.65（0.8 会污染人脸）

## 3. 视频后

- [ ] **没走 ken_burns 降级**——查日志 `mode=`，真视频才是 `wan5b`
- [ ] 运镜幅度没有大到糊掉（竖屏慢速小幅最稳）
- [ ] 单镜时长与 `dur` 设置一致
- [ ] 尾帧落点自然（xfade 处没有明显跳帧）

## 4. 配音与字幕

- [ ] **台词配音、旁白不配音**（这是定过的约定，别做反）
- [ ] 念出来的台词**画面上看得见**——字幕是两段式：上行灰白背景、下行暖黄台词
- [ ] 每个说话人音色不同且稳定（查 `cast.json` 的 `voice`）
- [ ] 无台词的幕补了静音轨，否则 concat 会错位

## 5. 成片

- [ ] 做了 faststart：`ffmpeg -i in.mp4 -c copy -movflags +faststart tmp.mp4 && mv tmp.mp4 in.mp4`
- [ ] 能在浏览器里播（atom 顺序应为 `ftyp, moov`）
- [ ] **静音播放一遍仍然看得懂**（这条最能暴露剧本问题）
- [ ] 前 3 秒有钩子，不是空镜慢慢推

## 常用命令

```bash
# 剧本校验
python scripts/script_layer.py check story/青囊_剧本.json

# 带角色外貌 + 全片风格出图（会改变参数指纹，需要重渲）
python scripts/novel_video.py --cast --style --neg base,face

# 只重新合成（图没变时）
python scripts/novel_video.py --compose

# 配音
python scripts/add_stepfun_tts.py qingnang

# 看断点续跑状态
python scripts/run_state.py show

# 查素材库
python scripts/promptbank.py list camera
python scripts/promptbank.py find 推
```
